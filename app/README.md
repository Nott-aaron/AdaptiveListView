# Experiment 7: Adaptive Android Application with ListView and ImageView

Android app demonstrating a custom ListView adapter that displays a list of items, each with an ImageView and TextView.

## Output
![App Screenshot](screenshot.png)

## Description
- Custom Adapter class extends ArrayAdapter
- Each list item row contains an ImageView and TextView (via list_item.xml layout)
- ListView displays a list of fruit names with icons
- Clicking an item shows a Toast with the selected item's name
